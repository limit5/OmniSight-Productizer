# Short imperative lesson title

**Situation**: What happened, with the concrete failure mode and context.

**Fix**: The specific change that resolved or prevents the issue.

**Verification**: The test, command, Gerrit change, or live observation that proves the fix.

**Generalisation**: The reusable rule future agents and operators should apply.
