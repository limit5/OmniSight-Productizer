## Decision — prod compose checkout ref
**Prod = clean DEDICATED checkout PINNED at the promoted release SHA** (advanced only by the deploy action), **NOT**
develop-tip-tracking and **NOT** the shared dirty runner tree. Rationale: the checkout supplies compose *topology*
(not app code — the app is the cosign-verified image); a develop-tip-floating topology could bring up a layout the
released image was never tested against on reboot (F5 relocated to the compose file). **Staging = repoint to
sora-bridge (develop-tip, monitored)** — staging SHOULD track develop-tip; prod should lag/pin/deliberate. This is
the operator's "2 個都做 + 正相關": prod pinned-release + staging develop-tip, both OFF the dirty runner tree.
