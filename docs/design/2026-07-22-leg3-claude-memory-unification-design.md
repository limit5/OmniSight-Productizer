## 0. Audit-decided architecture (constraints honored)
- **NEW `claude_memories` substrate** (0279): neither l3_facts (64-char closed values) nor learned_item_versions (8KB frozen cap + imperative-phrase bans — 2 corpus files trip `_TOOL_POLICY_RE` TODAY) can host the corpus. Clone the U4 governance PATTERN (state machine quarantined→published→superseded/revoked, transition_events, sha-bound rendered artifacts) with an OWN lint profile (size budget, secret-scan, staleness, dead-`[[links]]` — NO de-imperativization: authority lives in the kernel, not text filtering; Claude trusts its own PUBLISHED memory).
- **Files stay the write surface** (the harness auto-memory writer is unredirectable — two-writer reality); backend INGESTS (files→PG quarantine, governance-on-ingest); **regeneration = MEMORY.md ONLY**, session-boundary-timed, ingest-before-regenerate (never clobber a file whose sha changed since last ingest). This FIXES the live bug: MEMORY.md is 50.7KB vs the 24.4KB harness budget — recall is being truncated TODAY; a rank-ordered byte-budgeted regeneration is the payoff increment.
- **Identity**: dedicated `api_keys` bearer → `for_service("claude-code")` — revocable, auditable, non-authorizing.
- **Columns**: slug(unique/project), title, description, mem_type{project,feedback,reference,user}, body TEXT (verbatim), rank, links JSONB, origin_session_id, body_sha256, revision, state, created_by, project_id.

## 4. INTEGRITY-AUDIT CONDITIONS FOLDED (v1.1, 2026-07-22)
- **B1 (the check that matters)**: server-side "published+sha" claims are attacker-controlled under backend compromise — the regenerator VERIFIES CLIENT-SIDE: every exported row's `body_sha256` re-hashed against the LOCAL topic file (ground truth is already on Claude's disk; the loader :239 read-time re-hash idiom). Mismatch → exclude + `⚠ drifted` marker + alarm. Index-line text is length-capped + sanitized (it is unconditionally-injected prompt real estate).
- **B2 (reconcile, not refuse)**: MEMORY.md has TWO legitimate writers → pin mismatch fires routinely; a routine tripwire trains override. Mismatch = first-class RECONCILE (delta → quarantine flagged origin=drift → regenerate from published rows = poison evicted + surfaced). Hard-refuse ONLY for server-pin self-inconsistency or file-binding failures over threshold.
- **Dual-sided pin (one scheme cannot cover both threats)**: server export ledger (PG row {export_sha256, manifest[(slug,revision,body_sha256)]}) defends vs ~/.claude attacker; client file-binding defends vs backend attacker; local `.pin` demoted to two-writer race guard. HONEST GUARANTEE: index integrity holds iff ≥1 side uncompromised; bodies verify against local disk regardless; current-session harness injection is out of reach by design.
- **Re-publish semantics (γ-0)**: published revisions IMMUTABLE (partial unique index + UPDATE-reject trigger, 0259/0277 idiom); file edit of a published slug → NEW quarantined revision; publish N+1 ⟺ N→superseded same-txn; approval binds exact (version, revision, body_sha256) + lint-pass record — post-approval change voids; revoked slugs excluded from regeneration.
- **Publish gate (γ-1)**: own bind-gate trigger (0277 pattern, claude-shaped predicates — no eval lane); review surface = DIFF-vs-last-published for edits / full size-capped render for new slugs (never a 400-char keyhole on a 264KB body); `_WRITE_CAP_PER_HOUR` anti-rubber-stamp limiter.
- **Secret scan (γ-1)**: reuse `backend/security/secret_filter.py` patterns DETECT-ONLY (verbatim-mirror invariant — never rewrite; 422 → human fixes the file); localhost DSN allowlist (corpus has test-DB DSNs that would false-positive); ADD the Atlassian `ATATT` pattern (hottest secret class here, missing from the table). Live scan: zero real secrets in the corpus today.
- **Blast-radius honest statement (§2.3 rewrite)**: γ-2 gives a backend compromise authorship of SELECTION + RANKING + index-line text (~24KB injected tokens; guardrail-lesson suppression is the sneak) — NOT topic bodies. Client file-binding stops fabricated bodies; human gate stops silent export-set changes; server pin stops local-tamper persistence. Nothing protects the current session from an ~/.claude writer.
