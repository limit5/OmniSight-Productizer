## 形象細節（原創）
- **性格母題**：創作·色彩·排版·把介面變美。潮、有品味、表情豐富。
- 髮：時髦白+薄荷綠挑染短髮（有造型感、不亂）、俐落瀏海；一撮呆毛像游標「I-beam」。
- 眼：薄荷綠大眼、靈動有創意光；愛美的自信笑。
- 獸耳：白底薄荷綠**兔耳**（長、活潑,末端偶帶像素色點）；蓬圓兔尾。
- 上身：**潮流機能連帽外套/oversized 襯衫**（配色乾淨、有設計感）+ 印像素圖案短T + 掛一副降噪耳機/繪圖手套。
- 下身：時尚寬版短褲 or 束口褲 + 潮流運動鞋（設計師穿搭感）。
- **裝備（前端/UI）**：
  - 手持**觸控筆 + 半透明繪圖板/浮動 UI 畫布**（上面浮著正在排的 UI 元件、按鈕、卡片）
  - 腰間掛**調色盤/色票環**（薄荷綠主色的一串 swatch）
  - 肩頭飄**像素方塊/游標**、佈局網格線
  - 繪圖手套、量測尺
- 表情：有品味的自信笑、看到醜 UI 會皺眉、上稿時眼睛發亮。
- 氛圍母題（招牌色浮動）：🟩像素方塊 · 🎨調色盤 · ✏️觸控筆 · ▭UI 卡片/游標 · 網格線。
- 姿勢（全身）：**設計中的姿勢**，一手托浮動 UI 畫布、一手持觸控筆點畫，微側身展示作品；時尚俐落又有創作感。
