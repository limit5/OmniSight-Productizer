# OmniSight 角色設計聖經 v1（2026-07-02，operator 共同設計）

錨定所有角色的統一設計語言。新角色 = 查這份表 + 微調，確保 8+ 角色風格一致。

## 0. 總方向（operator 拍板，不可偏離）
- 全男性；年齡 12–50，**與能力/等級無關**（設計軸 ≠ 能力軸）
- **大部分＝可愛正太**，少部分＝青年/壯年
- 畫風：**日系動漫正太 · 賽璐璐（cel-shaded）上色**
- **獸耳正太/少年**（kemonomimi）為主要形象
- 風格承襲自 operator 參考圖（`atk-refs/ref1`：蓬鬆髮+挑染呆毛、大眼小虎牙、oversized 外套疊穿、choker、絕對領域、貼紙描邊+方格背景、閃電/掌印/星星氛圍母題）——**承襲畫風，不照抄該角色的貓耳/藍毛/服裝**。

## 1. 四個設計軸（每個角色由此組合）
| 軸 | 決定 | 規則 |
|---|---|---|
| **① 年齡帶** | 身形比例 | 正太=3–4頭身矮萌（多數）；少年=4–5頭身；青年/壯年=5–6頭身（少數，通常給資深老將如 iris/kai）|
| **② 腦 → 招牌重點色** | 主色調 | Claude=琥珀橙 `#d97706` · Codex=翠綠 `#10b981` · Gemini=靛藍 `#3b82f6` · Grok=桃紅 `#ec4899`。每角色的挑染/眼睛/服裝點綴用這色 |
| **③ 獸耳 → 個人母題** | 獸種+個性 | 每角色一種獸耳，選一個貼合公會/個性的動物（貓/狐/狼/兔/犬…），不重複 |
| **④ 公會 → 職業配件** | 服裝道具 | backend=工程圍裙/機械臂章 · frontend=調色盤/畫筆 · isp=相機鏡頭/取景框 · mobile=耳機/手機吊飾 · sre=工具腰帶/儀表 · auditor=盾/放大鏡/眼徽 · red_team=面罩/暗色系 |

## 2. 呈現規範（每個角色的成品）
- 半身或抱膝坐姿立繪 + 白色貼紙描邊 + 淺方格背景
- 招牌色 3 個氛圍母題浮在周圍（依角色定，如 argus=🛡️👁️🔍）
- 賽璐璐硬陰影、乾淨線稿、大眼、可愛表情

## 3. 交付分工（誠實的能力邊界）
- **我出**：設計聖經 + 每角色規格表 + prompt-ready 美術指導（可直接餵 AI 繪圖/繪師）
- **operator 執行**：實際立繪用 AI 繪圖工具（NovelAI/Midjourney 類）或繪師
- 定稿後：`character_def.appearance`（JSONB）存規格、頭像資產接進公會廳/AGENT MATRIX（屆時開票）
