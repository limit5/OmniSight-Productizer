# OmniSight production deploy ref allowlist (FX.7.9)
#
# Used by scripts/check_deploy_ref.sh + scripts/deploy-prod.sh to gate
# which final git tags may be deployed to production. Image digest deploys
# are accepted by the RT-07a shape gate and cosign verification path before
# this allowlist is consulted. Intent: prevent a misconfigured operator (or
# compromised CI runner) from shipping an arbitrary branch / personal fork to
# prod.
#
# Format: one rule per line. Lines starting with `#` and blank lines
# are ignored. Each rule is one of:
#
#   tag-regex    <ERE-regex>             # match tag name by ERE regex
#
# Rules are evaluated top-to-bottom; first match wins. If no rule
# matches the requested ref, the deploy aborts.
#
# Adding a new entry is a deliberate change reviewed in a PR — that
# is the audit trail for "who said this final tag is allowed to ship".

# Final semver release tags only (v1.2.3). Pre-release / hotfix suffixes
# are rejected by the RT-07a final-ref shape gate before allowlist matching.
tag-regex ^v[0-9]+\.[0-9]+\.[0-9]+$
