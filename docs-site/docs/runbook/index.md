# Runbooks

Step-by-step operator playbooks for live systems. These are the documents on
the oncall person's screen at 3am, so they err on the side of explicit
commands, expected output, and rollback paths.

The runbook corpus in `docs/runbook/` (GPG release signer setup, hotfix
workflow, post-deploy recovery) will be migrated in a follow-up ticket. This
scaffold reserves the section so the navigation structure validated in OP-786
matches the final layout.
